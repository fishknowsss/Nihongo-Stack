# Nihongo Stack · 日式学习工作台

范围仅 apps/codex。2026-10-07 用户先指定米白、朱红线框与日式质感；随后指出均匀朱线过于平淡、不易读、中心弱，要求调整样式、对齐、颜色和大量 UI 内容。最终版以任务效率与阅读层级为先。

## 视觉与排版

- 底色 #f4efe6，阅读内页 #fffcf6，侧目录 #eee7d9。墨色 #292822，辅助文字 #57544b，强调朱红 #b03027。
- 分隔线 #d9cebb；输入边界 #897968；朱红用于主要动作、当前状态和重点页脊，避免所有内容使用同一红框。
- 中文操作界面用系统无衬线，正文以 15～16px 为主；日文阅读用 Hiragino Mincho ProN / Yu Mincho。首页当前单元 34px，页面标题 30px，层级通过字重、对齐与背景区分。
- 少量 4px 控件与表面圆角；无大圆角统计卡、渐变、噪点、假纸纹或装饰性波形。
- 完成/正确答案用 #35583f 附文字，不仅靠颜色表达。

## 页面结构

- 今日：当前单元、日文主题、真实学习目标与下一步为中心；旁侧显示任务估时、完成数和时间调整；下面是具体任务表。主按钮直接说明“开始复习/阅读/听音”。
- 课程：桌面双列目录，窄屏单列；当前单元有明确状态，展示六张卡、阅读与听音的实际练习覆盖。
- 阅读/听音：材料数量、搜索/筛选/选择 → 内容与题目分区。宽屏正文保持可见，窄屏上下排列。原生 radio、select、audio 保留。
- 进度：分开课程覆盖、卡片复习、独立材料数量和累计作答；七天记录与历史列表不换算考试成绩。
- 设置：新卡量 → 导出/恢复 → 预览双方数量 → 默认未勾选的确认 → 恢复；本机导入前副本可导出。

## 输入、状态与事实

- 用朱红可见焦点，切页仅将正文滚动位置归零，焦点进入内容；无装饰性入场动画，尊重 reduced motion。
- 普通分隔线不承担控制边界的可见性；实际输入采用更深的中性边界。
- 每个页面都有直接行动、加载、已保存结果或空状态；草稿和结果不得被 UI 改版覆盖。
- “已练”是提交记录口径，不等于掌握。原创内容未经教师审校、新语音为合成练习等事实在材料与来源区保持可见。

## v0.3.0 新增界面

- 卡片库沿用列表与原生 details：日文表达为第一层，类型/单元/排程为第二层，释义按需展开；收藏保持独立按钮。最近困难以最后一次反馈为准。
- 每轮复习有明确结束与继续入口，不把一轮结束称为全部复习完成。快捷键在输入控件获得焦点时停用。
- 设置补充默认学习时间和每轮卡片量；写入期间禁用控件，完成后提示。
- 品牌图标统一使用 `public/app-icon-128.png`；桌面使用对应 ICNS，网页使用 32px favicon。生成来源与提示词见 `assets/ICON.md`。
- 窄屏底部导航保持七个学习入口与一个设置入口；控件至少 44px，极窄屏的学习入口可横向滚动；底部留白覆盖工具栏高度。

## v0.4.0 应用框架与复盘

- 外壳限定到窗口高度；侧栏和顶部工具栏不跟随正文滚动。正文为唯一主要滚动区；短窗口侧栏允许独立滚动，窄屏底部导航固定并留出安全区。保留系统滚动条和滚轮行为。
- 学习页顶部计时条为命名区域；计时数字不用 live region，避免每秒打断辅助技术。暂停和结束按钮可通过键盘操作。后台、失焦、手动暂停和超过 60 秒的闲置不计入。
- 进度页的错题列表保留原生 details，按材料最新作答计算；展开显示真实选择、正确答案、解析、材料入口与作答条件。未知历史材料保留在历史中，不猜测题目。
- 真实活跃时间从 v0.4 开始记录；旧经过时间不迁移为活跃时间，计划估时不自动调整。

## v0.5.0 Solid Glass 与学习回顾

2026-10-18 用户指定可采用 SolidGlass。本轮在原暖白朱红基础上采用 DeepLethe Solid Glass 的材料分层：薄层用于应用框架与工具条，较厚表面用于当前任务、阅读与设置，近不透明表面用于提示。边缘高光、细边和偏移柔影建立厚度，正文保持实底可读；圆角为表面 14px、控件 9px。覆盖前述 v0.2 的平面无阴影与 4px 圆角约定。使用原生 CSS 适配现有 React 界面，未引入 Tailwind/shadcn 迁移；上游 MIT 许可在 public/licenses/solid-glass.txt。

- 字体、中文操作、日文明朝体、朱红动作与固定应用框架延续。仅框架使用局部 backdrop blur；降低透明度偏好切换实底，降低动态偏好关闭控件过渡。
- 今日与七单元课程都有可折叠学习要点：原有阅读重点、六个词句、释义与例句、复盘提示。复用内容包中的原文，不增加进度写入或新的完成口径。
- 进度页的一周回顾合并原活跃时间区域，按截至昨天的七个完整自然日呈现类型汇总、逐日时间/反馈/提交和任务调整原因。今天的活跃时间单列；不在整周汇总中使用未结束的今日数据。
- 静读超过 60 秒可能少计。只给基于本机记录的观察提示；手动调整每日预算，不将日总活跃时间推算成每份材料估时。

## v0.6.0 显示与交互校正

2026-10-18，用户要求全面审查显示、配色、组件对齐、易读性和效率，并尝试 FuriFont。以学习任务与可读性为准，替换过去多轮叠加的覆盖样式：styles.css 负责布局与组件，solid-glass.css 只负责材料 token 与应用框架。此前尺寸与颜色以本节为准。

- 统一暖白层级：canvas #f4f2ed，正文 surface #fffefa，框架/辅助面 #eeebe4；墨色 #302d28，次要文字 #625d54，朱红 #a73127。输入边界 #968d80；正确 #345b41，错误 #9b2f25，均附文字。主文本与控件保持清楚边界。
- 表面圆角 10px，控件 6px；玻璃高光与阴影仅承担层级，阅读材料使用实底。正文界面 15px、普通按钮和筛选 14px、提示 13px、来源 12px；日文正文 22px，移动端 20px；保留注音足够行距。
- 固定外壳延续：208/180px 侧栏、60px 顶栏，正文独立滚动。控件最低 44px；select 保留原生语义与弹出菜单，统一外观以修复 WKWebView 的高度差异。
- 课程单列连续目录；单元编号、标题、状态、主动作与材料入口有固定对齐关系。学习要点展开只影响本单元；词句、释义和例句在宽屏按列对应，窄屏纵向排列。
- 卡片库每批 20 张，可继续显示全部 62 张；检索/筛选重置显示批次；收藏与词条分开。查看提示在展开后不抢占注意力。
- 阅读/听音工具条收紧：宽屏一行，窄屏搜索一行、筛选与当前材料一行。筛选排除当前材料时仍显示实际当前项，并标注筛选外；清除筛选保留当前作答。
- 理解题显示已答数量，提供跳到首道未答题的键盘焦点入口。窄窗口阅读提供原文/理解题互跳。复习反馈后，新卡进入正文可见区域；单选控件用整行焦点，不叠加两套描边。
- FuriFont Serif v0.5.1 按需从本机包加载；阅读可选关闭/材料注音/字体注音，例句与已展开的听音文本可选字体注音。已有 ruby 优先，ss01/rclt 关闭 ruby 内的自动注音。rt 用 visibility 切换以兼容 WKWebView。辅助使用纳入原 readingHelp，重练重置；复习题面、选项、未展开听音文本保持原状。字体失效有明确错误和可用的重试。
- 不修改现有内容 ID、文字、题意、排程和备份 schema。一周回顾继续使用已记录的真实活跃时间；日历的作答数包含起点小测，与活跃日口径一致。

## v0.7.0 日语学习层与 JLPT 工作台

- 学习层固定为罗马音在最上方、平假名在汉字上方、释义/语法在原文下方；材料提供的整段 reading 优先于词典切词，避免多词短语的注音错位。
- 阅读、听力、卡片例句和课程要点共用 `LayeredJapanese`；听力 transcript 与课程材料在运行时提供逐段读音覆盖。卡片例句不把词条 reading 误用为整句 reading。
- JLPT 题干只在有明确引号目标词时叠加对应读音层；题干其余部分保持原文，避免把单词读音错误套到整句。
- JLPT 页区分原创教学包、官方公开入口和授权完整题库；每级教学包覆盖四类题型，完整题库支持学习/考试模式、官方时长倒计时、分科进度、分科得分、错题次数、52 个场次/等级位置统计和本机批量导入。
- 公开资料路线按日文 Can-do 目标和中文复盘方法组织，资料保持外链，不复制来源内容。
- 选中解释弹层保留 Solid Glass 轻层背景、朱红焦点和 reduced-motion；支持 Escape、键盘焦点、收藏、笔记、公开词典回退和进度页回看。笔记可在进度页直接编辑，删除笔记和取消收藏是两个独立动作。
