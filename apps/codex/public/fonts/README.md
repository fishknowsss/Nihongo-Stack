Font shaping annotates Han runs without sentence context. The app offers it explicitly as a reading aid, leaves original text intact, preserves supplied ruby and disables automatic font annotations inside ruby with ss01/rclt. It is never applied to the recall prompt or hidden listening text. When used before reading submission, it participates in the existing readingHelp evidence.
