# 文档导航

当前项目的入口文件保留在根目录：

- [README.md](../README.md)：项目总览与当前入口。
- [DECISIONS.md](../DECISIONS.md)：当前产品决策和范围边界。

其他文档按用途归档：

- `architecture/`：内容模型、学习系统和早期 MVP 技术计划。
- `planning/`：开发前评审、产品改进计划和各版本后续安排。
- `releases/`：v0.2–v0.6 历史交付记录。
- `content/`：私有 JLPT 资源和内容来源说明。
- `archive/research/`：旧的 Japanese Workbench 参考讨论稿，只作历史资料。
- `mygo-migration.md`：当前 MyGo 架构、构建和数据兼容说明。

`output/` 保存截图、日志和验收证据；`apps/nihongo-stack/` 只保留应用运行所需的 README、产品说明和设计说明。
