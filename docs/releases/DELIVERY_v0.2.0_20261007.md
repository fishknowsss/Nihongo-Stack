# Nihongo Stack v0.2.0 · 本机交付

2026-10-07。桌面应用已重新打包、签名校验并打开。原有学习记录保留。交付范围是私人本机试用，P2 连续材料与产品入口完成试用版；专业教学验收与一周真实使用仍待完成。

## 应用与使用

- 最终应用：`apps/nihongo-stack/Nihongo Stack.app`，版本 0.2.0，bundle identifier 仍为 `com.nihongostack.desktop`。
- 双击可使用，不需要终端或本地服务器。在「课程」选单元，在「今日」开始复习、阅读、听音。
- 「设置」导出 JSON；文件名含本地日期、时分秒与毫秒，避免同日导出仅使用相同日期名称。
- 学习记录、草稿、课程位置与任务调整都存在应用自己的本机数据库；与浏览器数据独立。

## 本轮改动

| 部分 | 实际交付 |
| --- | --- |
| UI 与页面 | 按两次用户反馈重做。米白内页、墨色正文、少量朱红主动作与页脊；当前单元及下一步形成中心。中文操作用系统字体，日文阅读保留明朝体；统一对齐、主次动作、状态与说明 |

| 练习 | 材料搜索/未练筛选、阅读/听音/小测草稿恢复、提交结果重开可查看、明确重新练习、真实 radio 与键盘作答 |

| 进度 | 分开课程覆盖、进入复习的卡片、独立材料数量和累计作答；近七天记录与历史列表，不预测 JLPT 分数 |
| 备份 | 一致事务导出、字段与重复 ID 校验、双方数量预览、默认未勾选的替换确认、本机导入前副本；移除原生无效的 window.confirm |

## 内容扩容

总计 **62 张卡、9 篇短文、10 段音频、7 个基础单元**。

- 原 v1 的 20 张卡、2 篇短文、3 段真人短句保持原样，已用 SHA-256 指纹核对。
- v2 新增 42 张卡、7 篇短文、7 段配套听音、21 道阅读题、14 道听音题、译文、解析与复盘目标。
- 单元依次是介绍自己、一天的时间、地点与交通、购物与数量、邀约与安排、天气与条件、综合复盘。
- 原创文本未取得专业日语教师/母语者审校；新增音频为本机 Kyoko 合成语音，仅作基础私人练习，不混入真人首遍表现。
- 内容组织借鉴[日本国际交流基金的 Can-do 方法](https://www.irodori.jpf.go.jp/en/about.html)，没有复制教材原文或音频。
