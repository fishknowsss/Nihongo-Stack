# Nihongo Stack v0.6.0 · 显示与交互改进

2026-10-18。已更新并打开 `apps/nihongo-stack/Nihongo Stack.app`，双击即可使用。

## 实际变化

- 统一颜色、字阶、控件边界、间距、对齐、悬停、焦点和禁用状态。将约 2825 行多轮覆盖样式整理为 568 行单一组件规则与材料 token，保留暖白、朱红、日文阅读和固定应用框架。
- 课程改为连续单列；学习要点独立展开，避免相邻单元的大块空白。词句、释义和例句按对应关系排列。
- 卡片库每批显示 20 张，可继续显示全部 62 张；筛选与检索重置批次，收藏保持独立。
- 材料筛选外的当前练习仍明确显示，不再出现选择框与正文脱节。阅读/听音工具条与设置动作对齐；窄屏工具条压缩到两行。
- 理解题增加已答数量和跳到未答题入口；窄窗口可在原文与理解题间互跳。复习评分后让新卡回到正文可见区域。
- 修复原生 WKWebView 下拉框被压小和材料注音隐藏的问题；下拉框保留原生菜单与键盘语义，触控/点击区域至少 44px。
- 接入 [FuriFont](https://furifont.antfu.me/) Serif Regular v0.5.1。阅读提供关闭/材料注音/字体注音；单元要点与卡片例句、已展开听音文本提供可选字体注音。原有材料读音优先，避免重复标注。字体离线随包提供，首次使用才加载，失败可重试。
- 注音使用纳入原有阅读辅助记录，重练重置；提交后查看不改历史结果。复习回忆题面和理解题选项不自动注音。

内容数量与既有 ID/题意保持：62 张卡、9 篇阅读、10 段音频、7 单元。数据库、排程、计时和备份 schema 保持兼容。
