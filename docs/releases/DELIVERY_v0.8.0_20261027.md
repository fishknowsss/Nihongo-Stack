# Nihongo Stack v0.8.0

本版把首页和学习队列收敛为连续学习入口，重点修正学习量被每日计划限制、首页信息分散和 JLPT 目标缺少时间感的问题。

## 新增

- 首页显示 JLPT N2 距目标日期的剩余天数和小时数。
- 首页增加两个并列模块：可刷新、可翻面的随机卡片练习，以及当前阅读材料的日文原文、中文译文和理解重点。
- 复习设置支持“全部”批次，方便一次继续处理当前待练内容。

## 调整

- 新卡队列不再按每日新卡上限或今日建议时长截断，当前单元优先后继续展示其他未引入卡片。
- 首页改为单一连续学习页，集中呈现当前单元、下一步、三类学习入口、随机练习和详细译文。
- 首页建议时长只用于节奏提示，不限制复习、阅读、听力或 JLPT 学习量。
- 设置页移除每日新卡上限，保留复习批次作为界面分组方式。

## 验证

- `npm run build`
- `npm run test:learning`
- `npm run test:content`
- 浏览器检查首页倒计时、随机练习翻面、今日详解和复习队列
- MyGo macOS arm64 构建与 DMG 生成

内容数量、IndexedDB 备份格式和既有学习记录 ID 保持兼容。
