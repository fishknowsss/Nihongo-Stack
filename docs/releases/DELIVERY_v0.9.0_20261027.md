# Nihongo Stack v0.9.0

本版完成首页与全局排版的深度重构，重点修正入口混乱、内容拥挤和日文学习层错位。

## 首页

- 采用“高效学习中心”布局，把课程、复习、阅读、听力和 JLPT 入口集中到首页上方。
- 保留当前单元、下一步、JLPT 天数与小时倒计时。
- “随手学一题”和“今日详解”继续作为两个并列学习模块。
- 桌面端首页核心内容保持在一个视窗内；移动端自然降级为可滚动纵向布局。

## 排版与 UI

- 修正日文段落、ruby 注音、罗马音、释义层、JLPT 题干和选项的换行规则。
- 减少中文和日文混排时的异常断行、过度压缩和内联 flex 造成的竖排。
- 统一学习入口、学习卡、阅读材料、题目选项和辅助提示的对齐与文字层级。
- 资料页、阅读页和 JLPT 页完成桌面端视觉复核。

## 图标

- 保留原书籍、书签、米白底板和朱红配色。
- 将书面中央的“日”替换为日语平假名「あ」。
- 更新 MyGo 桌面图标、侧栏图标和 favicon。

## 验证

- `npm run build`
- `npm run test:learning`
- `npm run test:content`
- Impeccable mechanical detector
- 浏览器桌面与移动端首页检查
- 资料阅读页与 JLPT 页排版检查
- MyGo macOS arm64 构建
